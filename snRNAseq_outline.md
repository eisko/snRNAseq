# snRNAseq Analysis Outline

The purpose of this document is to outline analysis steps for single nuclei RNA sequencing (snRNAseq) data.
I have also provided links to several resources to provide additional information and context for this experiment.

## The data
The data was generated by Emily and Lauren. We isolated nuclei using **protocol XXX** (need to upload to github) and used the flow core on campus to sort nuclei by size and DAPI content.
The sorted nuclei were then handed off to the single-cell core (John Preall, Claire Regan, and Evan). The data was ran through the 10x machine with a target goal of ~10,000 nuclei.
The core prepared a sequencing library and processed the data using the **CellRanger** pipeline (provide link).

Roughly, CellRanger takes the raw sequencing files (fastq) and
1. performs quality control
2. Aligns to a given genome - in this case the lab mouse genome (mmXXX???)
3. Groups reads by cell barcode and UMI
4. Counts aligned reads to create cell x gene matrix

The output of **Cell Ranger** includes the following (useful/relevant) files:
- `XXX.html` - provides quality control measures
- `XXX.cloupe` - condensed file used for preliminary inspection of data using Cloupe browser (provide link/tutorial?)
- `XXXfiltered_barcodes.h5` - file can easily be read into python/R for analysis, contains cell x gene matrix

Most of the snRNAseq analysis will focus on processing and plotting the `.h5` file.

## Goals of initial analysis
The goal of the initial analysis is to label nuclei by cell type and align these cell types between our lab and singing mouse data.

I suggest working your way through the following resources to guide the analysis:
- scanpy tutorial (link)
- scRNAseq textbook

Roughly, the steps involve:
1. Inspecting data for quality control and perhaps some initial filtering
2. Filter data - includes removing "soup" (i.e. extraneous RNA in collection buffer) and removing "doublets" (two cells/nuclei ber droplet)
3. Normalization
4. Feature selection
5. Dimensionality reduction
  - The most straightforward/simple dimension reduction is PCA, here's a paper (link) for an explanation that I like. You don't have to worry about understanding the math, but provides the linear algebra behind a PCA if you're interested!
6. Visualization
  - tSNE and UMAP are standard visualization methods in the field - see (link) for comparison and brief explanation of parameters
7. Clustering
  - Classic examples: k-means, hierarchical, up to you to decide what's best! (Can also ask Lauren)
8. Annotation
  - This is the trickiest and least straightforward part... If you get this far we can discuss further on different approaches you can try, will try to write out if I have time

Steps 3-6 are pretty standard for any machine learning or data science project and could theoretically be applied to other data types.
